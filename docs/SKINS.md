# Скины: что можно, чего нельзя и как это влезет в PSP

## Короткий ответ

| Вопрос | Ответ |
| --- | --- |
| Читать `.osk` (дефолтный stable-скин, Moonshine 2.1 Eclipse и любые другие) | **Да**, технически это обычный zip с PNG/WAV и `skin.ini` |
| Класть эти файлы в репозиторий или в собранный EBOOT | **Нет**, это чужие ассеты: дефолтный скин stable принадлежит ppy, Moonshine — автору |
| Грузить скин, который игрок сам положил на Memory Stick | **Да**, это не распространение — ровно так работает сам osu! |
| Свой скин «из коробки» | **Да**, но только собственный (процедурная графика или CC0/OFL-ассеты) |

Правовая логика простая: MIT-лицензия osu!lazer покрывает **код**, а не картинки и звуки.
У большинства скинов в `.osk` лицензия вообще не указана, то есть по умолчанию «все права
сохранены». Поэтому единственная безопасная схема — как у самого osu!: игра умеет читать
скины, но не поставляет их.

## Что технически лежит в скине

```
skin.ini            Name, CursorExpand, SliderStyle, [Colours] Combo1..8, [Fonts]
hitcircle.png       + hitcircle@2x.png, hitcircleoverlay.png, hitcircle-0..N.png (анимация)
approachcircle.png
sliderb0..9.png     sliderfollowcircle.png, reverseslider.png, sliderpoint10/30.png
spinner-*.png       spinner-background, spinner-circle, spinner-metre
cursor.png          cursortrail.png, cursor-middle.png
default-0..9.png    combo-цифры (или scorefont)
hitnormal / hitclap / hitfinish / hitwhistle .wav
```

Скины бывают 1x и 2x: `hitcircle@2x.png` — это 256×256 вместо 128×128.

## Почему «взять как есть» не выйдет на PSP

| Ограничение | Следствие |
| --- | --- |
| VRAM 2 МБ на всё | `hitcircle@2x` 256×256 RGBA = 256 КБ. Полный 2x-скин не влезет даже близко |
| RAM 32/64 МБ | Нельзя держать распакованные PNG и аудио целиком |
| Нет аппаратного PNG/JPEG | Декодировать PNG на устройстве = тащить zlib + память на буферы |
| Слабый CPU (333 МГц, софт-float) | Декодирование OGG/Vorbis в реальном времени дорого |

Поэтому скин **конвертируется заранее** на ПК, а на PSP приезжает уже готовый пак:

```
osu_skinpack  Moonshine2.1Eclipse.osk  ->  moonshine.spk
```

Что делает конвертер:

1. Читает zip, находит нужные элементы (игнорирует 90% того, что не используется в standard).
2. Даунскейлит 2x до 1x, а крупные элементы — до ~96–128 px (круг на экране PSP и так ~40 px).
3. Квантует в 8-битную палитру (CLUT8) или 4-битную: 128×128 CLUT8 = 16 КБ вместо 64 КБ.
4. Склеивает всё в атлас, чтобы рисовать одним вызовом GU на элемент.
5. Анимации сохраняет как список кадров с таймингом из `skin.ini`.
6. Хитсаунды переводит в PCM WAV 44.1 кГц (или ATRAC3, который декодирует Media Engine).
7. Пишет `.spk` с оглавлением: имя, версия формата, таблица элементов, атлас, звуки.

Игра на PSP читает `.spk` с Memory Stick потоково: атлас → VRAM, звуки → по требованию.

## Что делаем по умолчанию

- `assets/skin_default/` — собственный минимальный скин: круги, слайдер, курсор, цифры
  рисуются процедурно (уже так работает software-рендерер и GU-сцена).
- В настройках — выбор скина из `ms0:/PSP/GAME/OSUPSP/Skins/*.spk`.
- `.osk` кладётся в `Skins/` и конвертируется либо на ПК утилитой, либо (позже) на самой PSP,
  если хватит памяти; пока рекомендуем ПК-путь.

## Про osu!lazer

Код lazer — MIT, поэтому его **процедурные** скины (Argon, Triangles) можно портировать
с указанием авторства: там значительная часть графики рисуется кодом, а не берётся из PNG.
Это хороший источник вдохновения для собственного дефолтного скина, но конкретные файлы
всё равно нужно проверять по их собственным лицензиям перед тем, как коммитить.
