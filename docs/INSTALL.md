# Установка osu!psp на PSP — пошагово

Инструкция для случая «я вообще не в теме»: что скачать, куда положить, как запустить.

## 0. Что нужно

| Что | Зачем |
| --- | --- |
| PSP с **кастомной прошивкой** (ARK-4, ARK-5, PRO) | обычная прошивка не запускает homebrew |
| Memory Stick или карта памяти с адаптером | туда кладутся файлы игры |
| Кабель USB (или картридер) | чтобы скопировать файлы с компьютера |
| Карта `.osu` + `.mp3` | без карты запустится только демо-сцена |

## 1. Скачать EBOOT

1. Открой страницу Actions репозитория: `https://github.com/PoIYPo/osu-PSP/actions`
2. Выбери последний запуск с зелёной галочкой.
3. Внизу страницы, в блоке **Artifacts**, скачай `osu-psp-eboot`.
4. Распакуй zip. Внутри две сборки:
   - `build-psp/EBOOT.PBP` — обычная, играбельная;
   - `build-psp-audio/EBOOT-audio.PBP` — экспериментальная, со звуком.

## 2. Подключить PSP к компьютеру

1. На PSP: **Настройки > Соединение USB**.
2. На компьютере появится съёмный диск — это и есть Memory Stick.

## 3. Скопировать файлы

Создай на диске такую структуру (имена папок — заглавными):

```
PSP/
L-- GAME/
    L-- OSUPSP/
        +-- EBOOT.PBP          < сюда положи скачанный EBOOT
        L-- Songs/
            +-- beatmap.osu    < любая карта
            L-- audio.mp3      < музыка из этой карты
```

Пояснения:

- `EBOOT.PBP` — сама игра. Имя должно быть exactly таким (без «(1)» в конце).
- `Songs/beatmap.osu` — карта. Имя файла любое, но удобнее `beatmap.osu`: игра ищет именно его.
- `audio.mp3` — музыка. Имя должно совпадать с полем `AudioFilename` внутри `.osu`
  (обычно там `audio.mp3`, поэтому просто переименуй трек).
- Если музыка не нужна — можно не класть, игра пойдёт на встроенных часах.

## 4. Запустить

1. На PSP нажми **0** (или «Отключить» в меню), чтобы выйти из USB-режима.
2. В главном меню (XMB): **Игра > Memory Stick > osu!psp**.
3. Игра начнётся сразу: карта подгрузится, первые ноты появятся через ~1.5 секунды.

## Управление

| Кнопка | Действие |
| --- | --- |
| Аналоговый стик | двигать курсор |
| ? или 0 | удар по ноте |
| Удерживать ?/0 на слайдере | курсор сам едет по дорожке |
| SELECT | начать карту заново |
| HOME | выход |

Слайдеры в этой адаптации **доводятся автоматически**: попал в голову — держи кнопку, дальше курсор ведёт игра. Первые 6 секунд карты об этом напоминает подсказка `SLIDERS AUTO-FOLLOW`.

## Необязательные файлы

| Файл | Что делает |
| --- | --- |
| `PSP/GAME/OSUPSP/map.txt` | путь к карте, если она лежит не в `Songs/beatmap.osu`. Внутри одна строка: `Songs/MyMap/song.osu` или полный `ms0:/PSP/MUSIC/song.osu` |
| `PSP/GAME/OSUPSP/autoplay.txt` | автоплей: карта играется сама (демо/проверка) |

## Если что-то не так

| Симптом | Что проверить |
| --- | --- |
| Чёрный экран при запуске | папка ровно `PSP/GAME/OSUPSP`, файл ровно `EBOOT.PBP`, прошивка кастомная |
| Запустилось, но поле пустое | карта не найдена: положи `Songs/beatmap.osu` или создай `map.txt` |
| Нет музыки | в обычной сборке звук отключён; возьми `EBOOT-audio.PBP` и положи `audio.mp3` |
| Игра «замерла» на одном месте | выйди по HOME и запусти снова; если повторяется — пришли, какой EBOOT и какая карта |
| Не видно нот вовсе | карта может быть другого режима (osu!mania/taiko) — эта сборка играет только standard |

## Как обновить игру

Просто замени `PSP/GAME/OSUPSP/EBOOT.PBP` на новый. Карты и музыка останутся на месте.
